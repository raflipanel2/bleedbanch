IMAGE QUALITY

PPI, pixels and print size: a practical image quality test

Calculate effective print resolution using actual pixels and placed physical size.

BY BLEEDBENCH EDITORIAL09 NOV 2026~4 MIN READ

The word “300 DPI” often gets used as if it were a magic export switch. For photographs, the number that matters is effective pixels per inch at the final placed size. A small image labeled 300 ppi does not gain detail if you enlarge it to cover a poster. The relationship is straightforward: image pixel width divided by printed width in inches equals effective PPI.

Measure source pixel dimensions first

Check an image’s actual pixel count before placing it. A 2400-pixel-wide image laid out at 8 inches wide has about 300 effective PPI. The same image stretched to 16 inches has about 150 effective PPI. Changing only the metadata field in a file does not create new image information.

For a print image laid out in millimeters, divide the width in millimeters by 25.4 to get inches, then divide pixels by that number. Repeat for the height and use the smaller effective PPI as a conservative guide.

Match quality to viewing distance

Around 300 PPI is a common close-view commercial print target. Large displays viewed from several meters away may not need that density. Tiny fine type and logos can remain challenging even if the photograph looks acceptable.

There is no single safe cutoff for every paper, process or content type. Discuss the intended viewing distance, substrate, source sharpness and print technique with the provider rather than relying on a traffic-light number alone.

Beware of resampling

Upsampling software adds pixels by estimating missing information. Some advanced methods can improve perceived detail, but they cannot recreate all texture in an original low-resolution photograph. Upsampling repeatedly can make edges artificial.

If a photo is inadequate, first look for a larger original, reduce its placed size, crop differently, or replace it with vector artwork. Those changes are more reliable than a last-minute “300 DPI” checkbox.

Check effective resolution after scaling

Layout applications can report placed-image effective PPI, which may differ from a source’s nominal PPI. A 300-ppi photo enlarged to 200 percent is effectively about 150 PPI.

Do not ignore rotation and cropping: the visible region may use only part of an image. If you crop heavily and then increase the placement size, the remaining pixels can be insufficient even when the uncropped file looked large.

Keep vector art for sharp typography and marks

Text and clean logos remain sharp when exported as appropriate vector shapes or embedded fonts. A screenshot of a logo is a raster image and can become soft when enlarged.

Inspect output proofs at actual size and examine fine features. Excessive sharpening can create halos, so review both at normal size and close up rather than using zoom alone.

Try this calculation before buying a stock photo

A product image is 1800 × 1200 pixels and must appear 150 × 100 mm in a brochure. At that size, 150 mm is about 5.91 inches; 1800 divided by 5.91 is about 305 PPI. The height works out similarly. That is a comfortable starting point for many close-view photo applications. Now double the placed size to 300 × 200 mm and effective resolution falls to about 152 PPI without changing a single pixel.

A crop can make the issue worse. If only half the source width remains after cropping, the useful visible image may contain far fewer pixels. Keep the original image untouched and evaluate the final crop at its actual placed size. The Resolution Audit tool can test both orientations and different scale values.

Different content requires different caution

A soft background photograph on a large display may remain acceptable at lower effective PPI. A raster screenshot of a QR code or tiny specification table is much less forgiving: sharp, high-contrast edges are central to its function. Replace such artwork with native text or a vector QR code when the source permits.

Check for motion blur and excessive compression. A mathematically sufficient 300-PPI file can still look poor if the source was blurred or saved repeatedly as a low-quality JPEG. Conversely, good artwork viewed from across a hall may look fine with a lower density. A physical test strip is more useful than a fixed threshold.

Watch for this mistake

Changing an image’s resolution label from 72 to 300 without adding real pixels does not make a large print sharper.

Before you send the file

  • Record the image’s pixel dimensions, not only its file size.
  • Calculate effective PPI at the final placed width and height.
  • Check the closest expected viewing distance.
  • Prefer the original photo or vector art instead of unnecessary upsampling.

Where to verify the details

Production requirements differ among print providers. Check the specific job template and consult the BleedBench reference directory for manufacturer documentation on page boxes, bleed, effective PPI and PDF output. If a client or shop gives a different specification, obtain clarification before export.
