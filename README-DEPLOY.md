## Deployment
1. Extract the ZIP and upload its CONTENTS, not the folder enclosing them, to a GitHub repo.
2. Deploy as a static project in Vercel with no build command and output directory at the root.
3. Connect the final domain and ensure HTTPS works.
4. Verify /, /guides/, /tools/, /ads.txt, /sitemap.xml and /robots.txt in the live domain.
5. Open all tools in Chrome/Safari, check responsive layouts and console errors.
6. Submit sitemap.xml in Google Search Console. Evaluate indexing and verify the actual domain in AdSense, after final publisher config is confirmed.

## Design
Distinct Swiss poster / prepress-studio UI. Heading font Bricolage Grotesque, body DM Sans, technical UI Space Mono, delivered through Google Fonts with fallback fonts. No licensed font files are distributed. Flat illustration is a local SVG.

## Editorial and technical notes
- No invented reviewers, first-hand printer tests, or real-time news claims.
- Technical references appear in /sources.html. The two Print Notes are date-stamped reading notes, not a live release feed.
- Vendor-specific bleed, finishing, color and export settings override generic tools. This site is educational and cannot certify print-ready files.
- The sheet yield calculator uses basic uniform grid math, not mixed nesting.
